========================================================================
ICTL INTERPRETER - ALL SUPPORTED COMMANDS (QUICK REFERENCE)
========================================================================

TERMINAL I/O
  Terminal.Echo(<expression>)              - Print output
  Terminal.Ask(<prompt>)                   - Get user input  
  Terminal.Style(<color_or_style>)         - Set text color/style

VARIABLES
  Variables.New(<name>)                    - Declare variable
  Variables.<name> = <value>               - Assign value
  Variables.<name>                         - Read variable

MATH & COMPARISON
  Math.Eval(<expression>)                  - Calculate arithmetic
  Math.Compare(<a>, <op>, <b>)             - Compare numbers
  Data.Compare(<a>, <b>)                   - Compare data/strings

CONTROL FLOW
  Program.If(<condition>) { ... }          - Conditional execution
  Program.Main { ... }                     - Program entry point

LOOPS
  Program.Loop(<count>) { ... }            - Repeat N times
  Program.ForeverLoop { ... }              - Infinite loop
  Program.BreakLoop                        - Exit loop
  Program.Continue                         - Skip to next iteration

DATA TYPES
  Strings       - "text in quotes"
  Integers      - 42, -5, 0
  Floats        - 3.14, -2.5
  Booleans      - True, False

OPERATORS
  Concatenation - + (string joining)
  Math          - +, -, *, /, (, )
  Comparison    - >, <, >=, <=, ==, !=

SUPPORTED COLORS/STYLES
  "red", "green", "blue", "yellow", "cyan", "magenta", "bold", "reset"

========================================================================

QUICK EXAMPLE:

Program.Main {
    Variables.New(Count)
    Variables.Count = 10
    
    Program.If(Math.Compare(Variables.Count, ">", 5)) {
        Terminal.Echo("Count is greater than 5!")
    }
    
    Program.Loop(3) {
        Terminal.Echo("Looping...")
    }
}
