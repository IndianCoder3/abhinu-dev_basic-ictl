## Quick Start (TL;DR)

If you want to get started RIGHT NOW:

1. **Install ICTL** (see Chapter 2)

2. **Create a file** called `hello.ictl`:
   ```ictl
   Program.Main {
       Terminal.Echo("Hello, World!")
   }
   ```

3. **Run it:**
   ```bash
   ICTL-v1.0s.exe hello.ictl
   ```

4. **You're coding!** Now read Chapter 3 to learn more.
